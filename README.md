## 🔧 Local installation
### Setup
1. Install the repository dependencies
    ```
    npm install
    ```
2. Run the development server
    ```
    npm run dev
    ```
### Build
1. Generate the static build
    ```
    npm run build
    ```
2. To run the build execute the following command
    ```
    npm run start
    ```
